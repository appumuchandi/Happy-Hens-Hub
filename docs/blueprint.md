# **App Name**: HEN's HUB

## Core Features:

- Authentication: Firebase Email/Password Login
- Authentication & Roles: Role-based Access: Owner -> Full access (dashboard, egg collection, sales, reports, feed optimization). Worker -> Limited access (egg collection, view metrics, add sales). Viewer (optional) -> Read-only access to reports/metrics.
- Dashboard: Personalized dashboard per role. Key metrics displayed: Egg Count (daily, weekly, monthly), Hen Count (active stock), Feed Consumption (per day/week), Sales Revenue & Transactions, Profit/Loss overview (Owner only)
- Egg Collection: Workers/Owners can log daily egg collection. Data stored with date, batch, and worker ID. Owner can view trends across days/weeks.
- Sales Recording: Record sales transactions: Buyer name & contact, Date of sale, Quantity of eggs (tray/pcs), Total revenue. Access restricted to Owner & Workers.
- Reporting & Analytics: Production trends (daily/weekly/monthly egg count). Sales data (aggregated by buyer, date, revenue). Comparison charts (egg yield vs feed used). Downloadable reports (CSV/PDF for Owners).
- Feed Optimization (AI-powered): LLM analysis of past 7 days egg yield + feed data. Generates insights: Efficiency tips (e.g., “Increase protein feed by 5% for better yield”). Detect anomalies (drop in egg count vs feed given). Seasonal recommendations.

## Style Guidelines:

- Saffron Orange #FF9933 for CTA buttons, highlights, dashboard accents.
- Sky Blue #4BA3C3 for secondary actions, graphs, and calm info highlights.
- Dark Black #121212 for modern dark base for the app.
- White #FFFFFF for text, icons, and key contrast elements.
- Gray #2E2E2E for cards, panels, dividers.
- Deep Red #D72638 for error/warning highlights.
- 'PT Sans' (sans-serif, bold for headings, regular for content).
- Black cards with saffron borders and sky-blue graphs for a professional + farm brand feel.
- Primary buttons saffron, secondary sky-blue.
- Black background, saffron active tab, sky-blue hover/secondary tab.
- Sky-blue line charts, saffron bar charts for quick contrast.
- Green ✅ present, Red ❌ absent, with saffron highlights for monthly summaries.
